== Standard Interfaces

====
This section is out of date (#147).
The interfaces are declared in IDL, one per file in `interfaces/` (see <<idl>>), and most of those described here have no IDL declaration.

=== Rose

The _Rose_ interface provides operations common to all other interfaces.
It is implicitly inherited by every interface.

==== Operations

* *Destroy* Destroys the object associated with the capability.

=== Rose.Capability

Operations on capabilities.

==== Inherits

Rose

==== Operations

* *Create Entry* Manufactures a capability which can call the given endpoint
+
[source,ada]
----
function Create_Entry
  (Endpoint : Rose.Objects.Endpoint_Id)
  return Capability;
----

* *Create Endpoint* Creates a new endpoint and returns its identity.
+
[source,ada]
----
function Create_Endpoint
  return Endpoint_Id;
----

* *Receive Any* Respond to an invocation of any known capability.
+
[source,ada]
----
procedure Receive_Any
  (Called_Endpoint : out Endpoint_Id;
   Reply_Cap       : Capability;
   Parameters      : Invocation_Record);
----

* *Create Set* Manufactures a capability which represents a set of capabilities.
+
[source,ada]
----
function Create_Set
  return interface Rose.Capability_Set;
----

=== Rose.Launch

Launching processes.

==== Operations

* *Launch* Launches the process named by this capability.
Sent caps are copied to the process.
Returns a capability which implements the Processes interface for this process.
+
[source,ada]
----
function Launch
  (Caps : Array_Of_Capabilities)
  return interface Rose.Process;
----

=== Rose.System.Create

Interface for creating capabilities.

==== Operations

* *Create Capability* Manufactures a capability based on the representation given in the sent words.
+
[source,ada]
----
function Create_Capability
  (Header : Word_32;
   Payload_1, Payload_2, Payload_3 : Word_32)
  return Capability;
----

==== Derived Operations

* *Create Interface Capability* Manufactures an interface capability for the given endpoint and object.
+
[source,ada]
----
function Create_Interface_Capability
  (Endpoint : Endpoint_Id;
   Object   : Object_Id)
  return Capability
is (Create_Capability
     (16#0000_0005#, Endpoint,
      Low_Word (Object), High_Word (Object0)));
----

=== Rose.System.Device_Memory

Interface for setting up memory-mapped devices.

  (Base  : Physical_Address;

==== Meta Interface

[NOTE]
====
The meta interface no longer exists (#147).
The request below is drawn on the current invocation record, with the values of the original request.
====

The _meta_ interface is used for managing capabilities.
Sending to this interface creates new capabilities, or sends existing capabilities to other objects.
It can also be used to get a capability for an object's default interface.

[#interface-cap-request]
image::interface-cap-request.svg[Interface capability request]

The request sends two words: the interface id, and its version.
Its flags are `Send`, `Block`, `Send_Words` and `Recv_Caps`.

[#meta-interface]
.The meta interface
[cols="1,3,1,4",options="header"]
|===
| Endpoint | Name | Operations | Description
| 1 | Create Interface Cap | Send | Creates and returns a new interface capability for the sending object
| 2 | Create Endpoint Cap | Send | Creates and returns a new endpoint capability for the sending object
| 3 | Create Page Object Cap | Send | _data~0~_ contains page address; _data~1~_ contains the readable and writable flags
| 5 | Create Singleton Receive | Send |
| 6 | Create Cap Set | Send |
| 16 | Receive on provided caps | Receive | Maximum receive caps is 6
| 17 | Receive on any known cap | Receive |
| 31 | Exit | Send | End the sending process.
|===

==== The process memory manager interface

A server implementing the `procmem` interface can be notified when a process starts, when it ends, and when it requests access to virtual addresses which it does not currently have.

It is expected that the server will have access to a page mapper interface, which will allow it to map and unmap pages as required.
