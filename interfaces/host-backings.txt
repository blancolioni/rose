# The host backings (#1101): for each interface that a command built for
# the host can take, the type that implements its object type over the
# host's files, streams and clock. idle --target host --host-backings
# reads this, and refuses a command that takes any other interface
# (idle#133). The types are in src/library/host; each has an Open that
# binds an argument, from the text the user gave, or "".

Files.File                         Rose.Host.Files.File

Streams.Reader                     Rose.Host.Streams.Reader
Streams.Releasable_Reader          Rose.Host.Streams.Reader
Streams.Seekable_Reader            Rose.Host.Streams.Reader
Streams.Writer                     Rose.Host.Streams.Writer
Streams.Releasable_Writer          Rose.Host.Streams.Writer
